# Student Performance Prediction System

## Overview
This project predicts student marks using Machine Learning based on:

- Study Hours
- Sleep Hours
- Attendance Percentage

The model is built using Linear Regression and includes data visualization and performance evaluation.

## Features

- Data preprocessing
- Correlation heatmap visualization
- Linear Regression model
- MSE and R² evaluation
- User input prediction system

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run

```bash
pip install -r requirements.txt
python student_ml.py
```

## Sample Inputs

Study Hours: 9
Sleep Hours: 8
Attendance: 75

- Machine Learning Fundamentals
- Regression Modeling

- Model Evaluation
